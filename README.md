# God Bless América 路书

一本不出美国的全美洲文化之旅。灵感来自 Bad Bunny 在 Super Bowl LX 中场秀结尾的那一句 “God bless America”，以及他随后点名的 25 个美洲国家和地区。

打开 `index.html` 即可使用，无需构建。

- **航线**：12 站、26 天，从中场秀所在的 Levi's Stadium 出发，最后到波多黎各；也可以切换成纽约、迈阿密、波多黎各三站的精华 10 天。
- **路书**：每站的去处、吃的、路上听的歌，以及按出发日期推算的每站日期和当月节庆。
- **美洲护照**：按他点名的顺序列出 25 个国家和地区，去过就盖章（只保存在当前浏览器）。
- **节庆日历**和**出发前**须知。

资料核对于 2026 年 10 月，节庆日期和营业时间以官方信息为准。
